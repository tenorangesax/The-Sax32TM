# 6/13/2026 10 PM - Schematic + Project Start

_Time spent: 3.583333333333333h_

Today I started this project to learn more about how an ESP32 works, how it functions, and the basic requirements to get it running.

Here is the schematic I made:

![Screenshot 2026-06-13 at 5.51.21 PM](https://stasis.hackclub-assets.com/images/1781391087384-mmc82i.png)


The ESP32 I'm making uses a USB-C port with the data pins (D-, D+), the LD1117 (from the original ESP32) for regulating the voltage, then a button for BOOT and a button for EN (with an added capacitor and resistor for voltage stablization.

In the middle is the ESP32-S3-WROOM-1 chip, with WiFi and Bluetooth, and with its pins set up.

On the right is the pins (holes) for the ESP32, and below that is the LED indicators.

It is much more straightforward, and I used a lot of knowledge from my previous PI pico devboard.
